# تقسيم العمل — مستبدَل بالمراحل

> هذه الوثيقة **مستبدَلة**. التنفيذ صار بالمراحل (milestones). كل مرحلة تسلّم ميزات كاملة شغّالة، ويبني فيها عدة وكلاء بالتوازي، ويفحصها مدققون مستقلون.
> المرجع الملزم: [`docs/milestones/README.md`](./milestones/README.md)، وملف كل مرحلة في `docs/milestones/`.

## أين ذهبت المهام القديمة

| المهمة القديمة | المرحلة الجديدة |
|---|---|
| T00 الهيكل والعقود، T07 identity، T10 mobile shell، T10e حسابي، T20 التكامل (جزئياً) | **M0**: الهيكل الأولي العامل + تسجيل الدخول + بوابتا CI وأندرويد |

| T04 التوجيه، T06 الأقمار الصناعية، T10a الملاحة | **M2**: الاتجاهات والملاحة وطبقة الأقمار |
| T08 providers، T14 media، T16 الإدارة (التوثيق) | **M3**: وضع المزوّد والموافقات والتوثيق |
| T11 messaging، T15 notifications، T10d المراسلات | **M4**: محرك المراسلات والإشعارات |
| T12 assistant، T13 insights، T10b المساعد | **M5**: المساعد الذكي والأسعار والزحمة |
