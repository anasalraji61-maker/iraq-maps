# البدائل المؤقتة (mocks)

كل اعتماد يحتاج مفتاحاً أو حساباً خارجياً يُستبدل بـ fake أو mock حتى يوفّره المستخدم. المحوّل الحقيقي يُفعَّل بمتغيرات env فقط، ولا يوضع أي سر في المستودع (المستودع عام). الـ fakes تجتاز نفس conformance suite التي يجتازها المحوّل الحقيقي، و`packages/config` يرفض مرسلات الاختبار في الإنتاج. الفحوص الحية التي تحتاج هذه المفاتيح لا تحجب الإغلاق، لكنها تُسجَّل في ملف المرحلة كـ «نُفّذ» أو «لم يُنفّذ».

| الاعتماد | المرحلة | البديل المستخدم | ما يوفّره المستخدم للتشغيل الحقيقي |
|---|---|---|---|
| OTP عبر SMS أو WhatsApp | [M0](M0-walking-skeleton-login-gates.md)، [M3](M3-providers-media-verification.md) | `FakeOtpSender` في الاختبارات، و`FixedOtpSender` في e2e، و`ConsoleOtpSender` للتطوير. `packages/config` يرفضها في الإنتاج. | حساب مزوّد OTP (SMS أو WhatsApp) ومفاتيحه في env. |
| WhatsApp Cloud API | [M4](M4-messaging-inbox-notifications.md) | المحوّل يُختبر بحمولات مسجّلة وسر يُولَّد وقت التشغيل؛ القناة داخل التطبيق والتسليم اليدوي يعملان بدونه. | متغيرات `WHATSAPP_*` (phone number id، access token، app secret، verify token)، وقالب عربي معتمد، ورابط webhook عام. |
| FCM (الإشعارات الفورية) | [M4](M4-messaging-inbox-notifications.md) | `FakePushSender`؛ البناء ينجح بدون `google-services.json`، وتسجيل الجهاز يتراجع بسلاسة. | مشروع Firebase، و`google-services.json`، وحساب خدمة لـ FCM HTTP v1. |
| Anthropic API و `ASSISTANT_MODEL` | [M5](M5-assistant-insights.md)، [M7](M7-ops-privacy-budgets-rc.md) | `ScriptedLlmClient` في كل البوابات؛ مشغّل evals الحي يُتخطى عند غياب المفتاح. | `ANTHROPIC_API_KEY` و`ASSISTANT_MODEL` في env فقط، لا في المستودع. |
| تخزين S3 / R2 | [M3](M3-providers-media-verification.md)، [M6](M6-discover-activity-moderation.md) | محرّك تخزين على نظام الملفات للتطوير والاختبار و e2e؛ محوّل S3 يُختبر ضد خادم S3 HTTP وهمي. | bucket و endpoint ومفاتيح وصول (`S3_*`). |
| Sentry | [M7](M7-ops-privacy-budgets-rc.md) | `FakeErrorReporter`؛ المحوّل يتعطل تلقائياً عند فراغ `SENTRY_DSN`. | `SENTRY_DSN` (Sentry أو GlitchTip). |
| رابط API عام للتجربة على هاتف حقيقي | كل المراحل | المحاكي في CI مع خادم داخل الـ job على `http://10.0.2.2:3000`؛ شاشة «إعدادات المطوّر» لعنوان الخادم، و`pnpm dev:api` على نفس شبكة Wi-Fi. | خادم staging يصل إليه الهاتف، أو تشغيل الخادم على جهازه وضبط العنوان في التطبيق. |
| بيانات Geofabrik (في CI فقط) | [M0](M0-walking-skeleton-login-gates.md)، [M1](M1-map-search-place-card.md)، [M2](M2-routing-navigation-satellite.md)، [M7](M7-ops-privacy-budgets-rc.md) | fixtures يدوية محلياً (مثل `erbil-mini.osm` بترخيص CC0)؛ المستخرج الحقيقي يُعالج فقط في `geo-data.yml` على GitHub runners وتُرفع نتائجه كـ artifacts. | لا شيء للبوابة. اختيارياً: السماح بـ download.geofabrik.de للتشغيل المحلي. |
| Photon (geocoding) | [M1](M1-map-search-place-card.md) | مستبدَل ببحث PostGIS + pg_trgm في `modules/places` (ADR-0005)؛ `modules/geocoding` محجوز بعقد `GeocoderClient` فقط. | استضافة Photon مع بياناته عند الرغبة في تفعيله. |
| Valhalla (التوجيه) | [M2](M2-routing-navigation-satellite.md)، [M5](M5-assistant-insights.md)، [M7](M7-ops-privacy-budgets-rc.md) | wheel ‏pyvalhalla 3.9.1 محلياً على بلاطات fixture، وبلاطات المدينة الحقيقية في CI؛ الاحتياط ردود مسجّلة. | خدمة Valhalla مستضافة ببلاطات المدينة للإنتاج. |
| نطاق لروابط المشاركة | [M1](M1-map-search-place-card.md)، [M6](M6-discover-activity-moderation.md) | روابط التطبيق `iraqmaps://place/<id>` و`iraqmaps://post/<id>`. | نطاق (domain) واستضافة `assetlinks.json` لروابط https و Android App Links. |
| الاستضافة الإنتاجية | [M7](M7-ops-privacy-budgets-rc.md) | Dockerfile مع smoke في CI، و compose لبيئة تجريبية؛ البيانات والـ APK كـ Actions artifacts. | استضافة الخادم، و Postgres/Redis مُدارة، وتخزين كائنات و CDN، ورابط عام لسياسة الخصوصية، وحساب Google Play ومفتاح رفع خارج المستودع. |
| Android SDK محلياً | كل المراحل | `pnpm android:precheck` محلياً (prebuild + Metro export بلا SDK)؛ البناء الحقيقي في `android.yml` (ADR-0009). | اختيارياً: السماح بـ dl.google.com لتسريع البناء المحلي فقط. |
