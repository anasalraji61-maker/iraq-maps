# M7 Wave 10–12 — Comprehensive Developer Documentation

## Summary

Waves 10–12 of the M7 milestone produced a comprehensive documentation suite covering all aspects of the
Iraq Smart Maps codebase: architecture, module contracts, mobile design, deployment, and security. This
documentation brings the project to production-readiness from a knowledge-transfer and operations standpoint.

## Features Completed

### Wave 10 — Architecture and Module Reference

1. **`docs/ARCHITECTURE_DEEP_DIVE.md`** (809 lines)
   - Full system overview with ASCII architecture diagram spanning client, API gateway, domain, and data tiers
   - Request flow documentation (authenticated, public, and file upload paths)
   - Module interaction diagram showing all port dependencies and event flows
   - OSM → Import → Places → API → Mobile data pipeline documentation
   - Transactional outbox event flow with BullMQ queue diagram
   - Real-time integration (polling + push; WebSocket roadmap)
   - Caching strategy by layer (mobile React Query, Redis, PostgreSQL, PMTiles)
   - Complete database schema overview for all 10 active schemas
   - JWT authentication flow (OTP → access token → refresh → rotation → revocation)
   - Background jobs table with schedules and descriptions
   - All external service integrations (Claude API, WhatsApp, FCM, S3, Valhalla, Photon)

2. **`docs/MODULES.md`** (739 lines)
   - Module reference for all 24 modules (active, reserved, partial)
   - Per module: purpose, ports provided, ports consumed, events emitted/listened, DB schema, ENV vars
   - Covers: identity, providers, places, routing, geocoding, insights, assistant, messaging,
     discover, media, activity, notifications, reviews, moderation, analytics, and 9 reserved modules

### Wave 11 — Mobile Architecture

3. **`docs/MOBILE_ARCHITECTURE.md`** (462 lines)
   - Feature package structure: shell vs feature packages, shared packages
   - Complete navigation graph: all routes, modal vs push patterns, deep link entry points
   - State management: React Query for server state, React Context for UI state, AsyncStorage for persistence
   - Offline strategy: what works offline, what requires connectivity, error handling
   - Real-time integration: polling intervals, push → query invalidation code example
   - Deep linking schema (iraqmaps:// scheme + web fallback)
   - Push notification registration and delivery flow
   - Analytics tracking approach (server-side only, privacy-first)
   - i18n: locale priority, Arabic numeral formatting (ADR-0013), plural rules
   - RTL considerations: layout rules, MapLibre RTL text, component audit checklist

### Wave 12 — Operations and Security

4. **`docs/DEPLOYMENT.md`** (617 lines, replaces previous version)
   - Infrastructure requirements (minimum dev and production specs)
   - Complete environment variables reference (all 50+ vars, grouped by service)
   - PostgreSQL 16 + PostGIS setup (roles, extensions, migrations, tuning)
   - Redis 7 setup and configuration
   - S3-compatible storage (Cloudflare R2 + MinIO options)
   - Geo services setup (Valhalla, Photon, PMTiles generation)
   - Initial OSM data import procedure with verification SQL
   - First run checklist (infrastructure, security, functional, mobile)
   - Health check endpoints and uptime monitor table
   - Monitoring setup (Pino structured logging, Prometheus metrics, Grafana)
   - Backup strategy (PostgreSQL, Redis, S3, PMTiles) with retention schedule
   - Rollback procedure (API, database migrations, mobile)

5. **`docs/SECURITY.md`** (458 lines, new file)
   - Authentication: OTP flow, bcrypt storage, brute-force protection, JWT design
   - Token rotation and revocation architecture
   - HTTPS / TRUST_PROXY requirements
   - Authorization: role model (user/provider/admin), controller + service double-check pattern
   - Admin endpoint gating with ADMIN_KEY
   - Consent-gated data fields
   - Input validation: Zod schemas, phone validation, SQL injection prevention, XSS prevention
   - Rate limiting: per-endpoint limits table, response headers, DoS mitigation
   - File upload pipeline: MIME type + magic byte check, size limits, EXIF GPS strip, dimension bomb protection
   - Secret management: categories, gitleaks, rotation procedure
   - Data protection: phone encryption (AES-256-GCM), personal data minimisation, audit logging
   - GDPR: user rights implementation, account deletion cascade, DPA disclosures
   - Data retention policy table (all data types with retention periods and triggers)
   - Incident response: severity levels, 5-step response procedure, responsible disclosure
