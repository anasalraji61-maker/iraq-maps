# M28 — تبويب طلباتي في نشاطي

## الهدف

إضافة تبويب «طلباتي» في شاشة نشاطي، يعرض كل الاستفسارات التي أرسلها المستخدم مع حالتها (pending / replied / closed)، ويتيح فتح تفاصيل كل استفسار. يستكمل متطلب MVP «طلباتي ومراسلاتي» في شاشة نشاطي.

## معايير القبول

- [ ] تبويب جديد «طلباتي» يظهر في شريط التبويبات بعد «منشوراتي».
- [ ] يعرض قائمة الاستفسارات المرسلة من المستخدم (API: `GET /v1/inquiries`).
- [ ] كل صف يعرض: نص الطلب المختصر، عدد الأماكن المضمّنة، الحالة، والوقت النسبي.
- [ ] الحالة تظهر بنص عربي: «في انتظار الرد» / «تم الرد» / «مغلق».
- [ ] حالة فارغة واضحة ورسالة خطأ مع زر إعادة المحاولة.
- [ ] Pull-to-refresh يعمل.
- [ ] الواجهة RTL، كل النصوص عبر `t()`.
- [ ] يجتاز `pnpm turbo run lint typecheck test --filter=@iraq-maps/feature-activity`.
